# Employee Salary Management System - SAP ABAP

## Project Overview
Developed a payroll calculation system using SAP ABAP.

## Features
- Employee salary calculation
- Bonus calculation
- Tax deduction
- Net salary generation

## Concepts Used
- Variables
- Constants
- IF-ELSE
- Arithmetic Operations
- WRITE Statements

## SAP Transaction Used
- SE38

## Output
Displays employee salary report with bonus and tax details.
